# Договорености между проектите

Важат за nowcasting-public, airport-nowcast, MultiConvect, fog-model-bulgaria, fogNowcast и за портала.

**Личен проект, не е официален продукт на сертифициран доставчик.** Контакт: Илиан Манафов, ilianm@mail.bg.

## Общи правила

- Всеки източник се тегли веднъж, от един проект ([ownership.md](ownership.md)).
- Всички времена са в UTC, ISO 8601, с `Z` и секунди: `2026-11-26T06:00:00Z`.
- Вятърът е в kt навсякъде. Превръща се само при показване.
- Всеки публикуван JSON има общ заглавен блок ([header.md](header.md)).
- Всеки проект публикува `manifest.json` в корена на сайта си ([manifest.md](manifest.md)).
- Всеки публикуван формат се описва в `docs/` на проекта в същия PR, в който се появява.
- Работим на български. Код, имена на полета и коментари в кода са на английски, а README и `docs/` на български.

## Единици

| Величина | Единица | Поле |
|---|---|---|
| Температура, точка на оросяване | °C | `t`, `td` |
| Относителна влажност | % | `rh` |
| Вятър | kt, посока в ° (откъдето духа) | `wind_kt`, `wind_dir` |
| Налягане | hPa | `pressure_hpa` |
| Видимост | m | `vis_m` |
| Височина | m над морското равнище | `elev_m` |
| Вероятност | 0–100 % | `p_*` |

Липсваща стойност е `null`.

## GitHub Pages

- Кешът е `max-age=600`. Всеки, който чете чужд файл, добавя `?t=<число>` към адреса.
- Възрастта на файла се смята от `generated_at` във файла, а не от `Last-Modified`.
- Deploy заменя целия сайт на проекта. Всеки deploy съдържа всичко: страници, `manifest.json`, статични файлове и последната версия на всеки продукт. Историята е в клонове `archive-YYYY-MM`, не в Pages.
- Продукт с по-рядка честота се пренася между пусканията с `actions/cache`, не от живия сайт.
- Всички проекти са на един адрес (`ilianrvd.github.io`) и делят `localStorage`. Ключовете започват с името на проекта, напр. `airport-nowcast.lang`.
- В портала (`ilianrvd.github.io`) няма папка с името на repo на проект, защото тези пътища са на проектите.
